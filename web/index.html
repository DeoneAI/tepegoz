    Reference

    Storage
    Each session is a folder in data/ (JPEG frames, IMU CSV, telemetry, clock estimates, manifest), indexed in data/sessions.sqlite. Supabase mirroring of the session list is optional.
    Access
    On this PC no token is needed. A remote dashboard needs the collector token: run npm run token.
    Wi-Fi link
    Phones only expose camera and motion sensors on HTTPS pages. The collector opens a Cloudflare quick tunnel; install once with winget install --id Cloudflare.cloudflared.
    USB
    Needs Android Platform-Tools and USB debugging. The phone reaches the collector at its own localhost through adb reverse.
    Axes and units
    Phone portrait: +X right, +Y top, +Z out of screen. Accelerometer m/s² including gravity; gyroscope rad/s.
    Timing
    Browser monotonic time serialized as nanoseconds; the unit does not imply nanosecond precision.
    Calibration
    None claimed. Camera intrinsics and mount transform are uncalibrated.
