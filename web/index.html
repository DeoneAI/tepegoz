    Decisions so far

    Quick start

    Three steps to your first recording.

    No accounts, no configuration files.

    1. 1

      Start the collector on your PC

      In the project folder run npm start. It prints one link: open it and you are signed in.

    2. 2

      Choose how the phone connects

      Wi-Fi (any network, a secure link is created for you) or USB cable (Android).

    3. 3

      Scan and record

      Create a session, scan the QR code with the phone, tap Check sensors, then Start capture.

    Where is my data?

    On your PC, always

    Every session is a folder in data/: JPEG frames, IMU CSV, telemetry, clock estimates and a manifest. A local SQLite index makes the library fast; an optional Supabase mirror shares the session list with your team.

    Why a secure link?

    Phones require HTTPS

    Browsers only give camera and motion sensors to secure pages. The Wi-Fi option uses a free Cloudflare quick tunnel (install once: winget install Cloudflare.cloudflared). USB avoids it because the phone talks to its own localhost.

    Acquisition contract

    Transport
    HTTPS POST: timestamped JPEG frames plus batched telemetry. Bounded queue; overload skips are counted.
    Coordinates
    Phone portrait +X right, +Y top, +Z out of screen. Vehicle and camera extrinsics are uncalibrated.
    Angular velocity
    Browser rotation rate converted from deg/s to rad/s: X←beta, Y←gamma, Z←alpha.
    Timing
    Decimal nanosecond fields encode browser monotonic time. Nanosecond units do not imply nanosecond precision.
    Calibration
    No intrinsics or distortion calibration is claimed. Native Camera2/SensorManager is the next step for precise hardware timing.
    Week 1 gate
    Every frame timestamped; real accelerometer + gyroscope available and alignable; measured 2-minute recording, replay and stress report. The hardware gate stays unverified until tested on your phone.
    Step 2 of 3

    How should your phone connect?

    Your recordings are saved on this PC. Pick the way your phone reaches it.

    ✓ This PC's collector is connected

    Tepegoz opens a temporary secure (HTTPS) link to this PC. Phones only allow camera and motion sensors on secure pages.

    Starts automatically when you continue.
    1. Plug the phone into this PC with a USB data cable.
    2. On the phone: Developer options → USB debugging → On, then tap Allow.
    Needs Android Platform-Tools (ADB) on this PC.
    Advanced: use this dashboard from another computer

    Only needed for the online (Vercel) copy of the dashboard. The collector must allow that site in ALLOWED_ORIGINS.

    Start with a stationary test, then a handheld walking sequence. Record road-facing video only as a passenger.
